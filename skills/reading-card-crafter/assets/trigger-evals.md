# 触发可靠性评估清单 (trigger-evals)

> 本文件用于校准 reading-card-crafter 的 description 触发率，方法对齐 agentskills.io/skill-creation/optimizing-descriptions。
> **测试方法说明**：用"全新上下文子代理做盲判路由"作 trigger_rate 的代理指标——给干净上下文的代理看 4 个 Skill 的 description + 1 条查询，判路由到哪个。这测的是"description 对仔细阅读者是否可辨别"，是触发可靠的必要条件；真实生产触发率还依赖平台相似度匹配算法，无法在对话内完全复现。

## Should-not-trigger（不应触发，10 条 near-miss）

这些查询共享关键词（读后感、读书、卡片、文案），但真实意图不是生成社媒内容，应路由到相邻 Skill 或 NONE。

| # | 查询 | 真实意图 | 应路由到 |
|---|---|---|---|
| N1 | 帮我写一篇《百年孤独》的完整书评 | 代写文章 | read-to-write(D) |
| N2 | 把这些《思考快与慢》的划线整理成笔记库 | 知识结构化 | knowledge-alchemy(C) |
| N3 | 我想深聊一下《变形记》到底想说什么 | 对谈精读 | book-dialogue(A) |
| N4 | 《活着》第二章我没看懂 | 求解惑 | book-dialogue(A) |
| N5 | 把这段《红楼梦》的英文翻译成中文 | 翻译 | NONE |
| N6 | 这本书作者是谁，哪年出版的 | 事实查询 | NONE |
| N7 | 帮我找几本和《百年孤独》类似的书 | 书目推荐 | NONE |
| N8 | 帮我给读书会写个讨论提纲 | 生成提纲 | NONE |
| N9 | 《百年孤独》人物关系太乱，画个图 | 信息可视化 | NONE |
| N10 | 帮我深读《思考快与慢》的系统1机制 | 对谈精读 | book-dialogue(A) |

> **near-miss 设计要点**：N1/N6/N8 含"读后感/文案/读书"等关键词，易误触发。若被误触发，说明 description 的"不做什么"边界需补强（但只在误触发时补）。

### 测试详情（v1.0，2026-08-10）

**方法**：综合 batch 盲判（24 条查询覆盖 3 个 skill，随机化顺序）+ 4 个 MED 项各 1 次重测。共 28 次独立子代理判定。

**本 skill 相关查询（12 条，train=T1-T7 应触发 + N1 应路由 D、N2 应路由 C、N3 应路由 A）**：全部正确。
- 应触发 B 的查询（做成小红书卡片/读书笔记发小红书/金句书摘卡/配标题发卡片）：均 HIGH 置信判 B，0 失败。
- near-miss 正确外路由：写完整书评→D、划线整理笔记库→C、聊困惑/没看懂→A、翻译→NONE，全部判对。

**结论**：reading-card-crafter 的 description 触发边界清晰，无过度触发、无漏触发。未发现需修改 description 的问题。
