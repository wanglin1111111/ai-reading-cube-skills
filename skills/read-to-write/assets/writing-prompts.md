# 写作命题生成思路 (writing-prompts)

一个好的写作命题，是整篇文章的地基。它的公式：

```
命题 = 书的母题 × 你的真实切口
```

两边都得具体。"论人生"不是命题，因为它没有"你的切口"。下面是怎么把两边都弄具体的思路。

## 第一步：从书里取一个"母题"，而不是"主题"

- **主题**（太空）：《了不起的盖茨比》的主题是"美国梦"。
- **母题**（可用）：盖茨比对一个"回不去的过去"的执着；人如何与一个再也够不到的东西共处。

母题是可以**活在你身上**的东西，主题只是一个标签。命题要用母题。

## 第二步：找一个你的真实切口

向自己问这些问题，答案就是切口：

1. 读这本书时，哪一刻你停下来发呆了？为什么是那一刻？
2. 书里的某个处境，你经历过类似的吗？哪怕只有一点点像。
3. 读完后，你对某件原本笃定的事，产生过哪怕一秒的动摇？
4. 如果这本书早十年/晚十年读到，会不一样吗？为什么？
5. 书里有哪句话，你当时想抄下来发给某个具体的人？

切口要**小而真**。"我和我爸的关系"是大切口，"我爸生病那年我没哭，读这句时我哭了"是小切口。小切口能写出真文章，大切口只会写出空文章。

## 第三步：相乘，得到命题

把母题和切口撞在一起，命题就出来了。

| 母题（书） | 切口（你） | 命题 |
|---|---|---|
| 与"回不去的过去"共处 | 退学前最后一个下午 | 那个下午我做的每个决定，都是在告别一个回不去的自己——读《盖茨比》我想清楚了这件事 |
| 划线制造"已掌握"的错觉 | 考研背书背到崩溃 | 我背了三遍还记不住，读完才明白：我以为的"懂"，只是"眼熟" |
| "被爱"可以被替代吗 | 我养过又走丢的狗 | 克拉拉能替人类陪伴，但替代不了"被选择"——我的狗教我的事 |

注意命题都是**具体的、有"你"在里面的、可在一篇文章里讲完的**。

## 命题自检三问

给用户的命题，自己先过这三问：
1. **它有"你"吗？** 换个人能不能用同一个命题写出一样的文章？能 → 命题不够个人化。
2. **它够小吗？** 一篇文章（800-2000 字）讲得完吗？讲不完 → 太大，再收窄。
3. **它是命题还是主题？** 是个能争论的陈述，还是只是个话题标签？主题标签 → 改成陈述句。

## 当用户说"我没啥特别的经历"

很多人会卡在这里。这时不要逼用户编，而是换问法：
- "那你读的时候，身体上有过反应吗？想笑、不舒服、想合上书？"——身体反应是最诚实的切口。
- "书里你最不同意的一点是什么？"——反对也是切口，而且常常是好文章的起点。
- "如果要把这本书推荐给一个具体的人，你会推荐给谁、为什么？"——"为谁推荐"会逼出你和书的真实关系。

切口不是"惊天动地的经历"，是"你和这本书之间真实发生的那一点点事"。每个人都有。
