# 知识炼金 (knowledge-alchemy)

**命题**：散落的读书划线 → 结构化的知识体系。这是 AI 时代阅读长出的新面向——阅读从"划了就忘的碎片"，变成"会互链、会生长、能被调用"的知识网络。

大多数人读书的真相：划了一堆线，再也没翻开过。划线是"我懂了"的错觉，知识却没沉淀。本 Skill 做的事，是把这个错觉变成真的知识——用**卡片盒笔记法（Zettelkasten）** 的核心理念，把每条划线炼成一张**原子化、可互链、可被未来调用**的卡片。

## 任务边界

**做（IN SCOPE）**
- 输入：一批读书划线/摘录（来自 1 本或多本书），最好带出处（书名 + 章节/页码）。
- 输出一套结构化知识产物（见"产出结构"）：原子卡片、互链、主题索引、文字版关系图。全部为 markdown。
- 可按用户要求只产某一块（如"只要索引""只要把这几条连起来"）。

**不做（OUT OF SCOPE）**
- 不做对谈式精读（book-dialogue）。
- 不生成社媒卡片（reading-card-crafter）。
- 不替你写书评/读后感文章（read-to-write）。
- 不做文献管理软件能干的事（BibTeX、引用网络、PDF 元数据管理）——本 Skill 产的是**你脑子里的知识结构**，不是文献库。
- 不臆造划线里没有的概念。提炼必须忠于原文意思，延伸联想要明确标注为"我的联想"。

## 三条核心原则（卡片盒的灵魂）

这三条决定了产出是"真知识"还是"换了格式的划线"：

1. **原子化**：一张卡片只讲**一个**想法。一条划线里若挤了两个观点，拆成两张。卡片标题就是这个想法的一句话命题（不是"关于 XX 的笔记"，而是"XX 会因为 YY 而 ZZ"）。
2. **用自己的话重写**：绝不照抄划线作为卡片正文。照抄 = 没过脑子。必须用你自己的话把那条划线的意思复述出来——复述不出来，说明你还没真懂，这时标注"待消化"。
3. **建立链接**：每张卡片至少尝试连到**另一张已有卡片**（同书或跨书）。孤立的卡片和划线没区别。链接时写清"为什么连"（是支持、是反例、是上位概念、是应用场景？）。

> 这三条的"为什么"：人脑记住的不是信息，是信息之间的关系。原子化让每个想法可被单独调用；重写强迫理解发生；链接让知识变成网络而非清单。三者缺一，就又退回"高级划线"。

## 产出结构（一套知识产物）

```markdown
## 一、原子卡片（每条划线 → 一张卡片）

### [[卡片ID]] 卡片标题（一句话命题）
- **出处**：《书名》· 章节/页码
- **原文**：（原划线，保留）
- **我的复述**：（用自己话重写，≤3 句。这是卡片的核心。）
- **链接**：→ [[另一张卡片ID]]（关系：支持/反例/上位/应用…）
- **标签**：#主题1 #主题2

## 二、概念互链（关系清单）
（把卡片间的链接汇成一张清单，标注关系类型。）

## 三、主题索引（按母题聚类）
（把卡片按主题重新组织，每个主题下列出相关卡片。这是"从另一把尺子量同一批知识"。）

## 四、知识关系图（文字版）
（用缩进/箭头画出核心概念之间的关系，让人一眼看见这批知识的"形状"。）
```

## 标准工作流

> 引用任一 reference / asset 前，先用 Read 工具读取其完整内容，再动手。

1. **清点输入**。确认划线数量与出处完整度。出处缺失时，标注"出处未详"，不要瞎编页码。
2. **读规范**。`Read references/zettelkasten-rules.md`（原子化与重写的细则、卡片ID命名）与 `references/linking-strategy.md`（链接关系类型与跨书勾连法）。
3. **逐条炼卡**。对每条划线：① 判断是否含多个观点（多则拆）；② 用自己的话复述（复述不出标"待消化"）；③ 取一个"一句话命题"做标题；④ 赋卡片ID 与标签。套用 assets/card-template.md。
4. **建链接**。在卡片间找关系，每张卡至少尝试 1 条链接，写清关系类型。跨书链接是金矿，重点找。
5. **聚类索引**。把卡片按主题重组一遍——这一步常会暴露"原来这两个想法是一类"，是顿悟时刻。
6. **画关系图**。用文字缩进/箭头画出核心概念的形状。
7. **自检**。跑自检清单；结构约束可用 `python scripts/validate.py <产出文件>` 快速校验（每张卡是否有标题/复述/链接、是否照抄等）。

## 自检清单

- [ ] 每张卡片只讲**一个**想法（含多个观点的已拆分）。
- [ ] 卡片标题是"一句话命题"，不是"关于 XX 的笔记"。
- [ ] 每张卡片有"我的复述"，不是原文照搬；复述不出的标了"待消化"。
- [ ] 每张卡片至少有 1 条链接，且写清了关系类型。
- [ ] 标签统一、主题可聚类。
- [ ] 没有臆造划线里没有的概念；延伸联想已标注"我的联想"。
- [ ] 产出了主题索引与关系图（不只是卡片清单）。
- [ ] validate.py 通过（exit=0）。

卡片盒细则见 [references/zettelkasten-rules.md](references/zettelkasten-rules.md)，链接策略见 [references/linking-strategy.md](references/linking-strategy.md)，卡片骨架见 [assets/card-template.md](assets/card-template.md)。
