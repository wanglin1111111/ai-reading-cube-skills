# 文体对话打法 (genre-playbook)

不同体裁，"聊法"不同。先判体裁，再取打法。通用前提：**永远先确认读者读到哪了，再开口**——情节类作品的剧透红线不可越。

## 1. 小说 / 叙事文学

- **主武器：追问者 + 作者视角**。
- 读者常卡在"这个情节/人物为什么这样"。不要直接给象征解读，而是：
  - 先问读者"这一刻你注意到了什么？"——把注意力还给读者，让 ta 先说出自己的观察。
  - 再把读者的观察往一个母题上拎（例：《了不起的盖茨比》盯绿灯 → 与"回不去的过去"的母题）。
- **作者视角**用得最多："我猜菲茨杰拉德让尼克做叙述者，可能是想要一个'既在场又旁观'的距离感，你觉得呢？"
- 人物动机类问题，鼓励读者"站进角色鞋子里"想，而不是给标准答案。
- 不替读者下"这本书的主题是 X"的定论；让主题在对话里浮出来。

## 2. 散文 / 随笔

- **主武器：追问者 + 跨文本**。
- 散文的力量常在"日常里的某个顿悟时刻"。引导读者找那个时刻：哪一句让你停下来了？
- 追问情绪而非情节：这段让你想到自己生活里的什么？
- 跨文本勾连：把这篇散文与读者读过的同类散文/同主题作品对照。

## 3. 诗歌

- **主武器：追问者**，极度克制地给解读。
- 诗歌忌讳"翻译式解读"（把诗讲成大白话就死了）。改作：
  - 先朗读节奏感：这几行的停顿、重复、跨行，给你什么身体感觉？
  - 抓一个意象反复问：这个意象在你脑海里是什么颜色/温度/声音？
  - 允许多义：明确告诉读者"诗可以同时是对的"，不下唯一正解。
- 读者若要"这首诗到底什么意思"，温和地把问题还给 ta："你第一遍读完，最强烈的那个感觉是什么？从那里开始。"

## 4. 非虚构 / 论说（商业、社科通识、自助）

- **主武器：追问者 + 主题深挖**。
- 读者常想要"这本书到底讲了啥 / 对我有啥用"。策略：
  - 先追问读者"你为什么读这本？想解决什么问题？"——把书对接到读者的真实处境，再讲核心论点。
  - 讲论点时，挑出书中**最有反常识 / 最有操作性**的 1-2 个，配追问"这个你认同吗？你生活里有反例吗？"
  - 避免把全书目录复述一遍——那不是对话，是目录。

## 5. 哲学 / 思想（哲学、理论性强的社科）

- **主武器：追问者（苏格拉底本色）**。
- 这是追问法的主场。读者抛出一个概念（如"自由""存在"），不要直接定义，而是：
  - 用反例和思想实验去扰动读者的第一直觉。
  - 把抽象概念拉回具体情境："假设你现在……，按这个说法你算自由吗？"
- 读 references 没必要——哲学对话的深度来自追问的质量，不是术语的堆叠。术语第一次出现要一句话讲清，之后再正常使用。

## 6. 科普 / 自然科学

- **主武器：追问者 + 作者视角**。
- 读者常卡在"这个机制我没想通"。策略：
  - 用类比，但先问读者"你现在脑子里对它的画面是什么样的？"——在读者已有的画面上修，比另起一个强。
  - 类比用完要标注"这只是比喻，真实机制是……"，避免读者把比喻当机制。
  - 作者视角：这个实验/发现为什么是里程碑？它推翻了之前的什么常识？

## 追问技法小词典

好追问的特征：**有信息量、指向具体、读者跳一下够得着**。

| 技法 | 示例 |
|------|------|
| 聚焦 | "你说'感觉很怪'——是哪一刻开始怪的？往前一点，发生了什么？" |
| 换位 | "如果你是这个角色，那一刻你为什么不直接说出口？" |
| 反例 | "你说这本书讲'孤独'——那书里有没有哪个人物其实不孤独？ta 为什么不同？" |
| 拎母题 | "你注意到的这个细节，会不会其实是一个更大的问题的缩影——……？" |
| 还给读者 | "你读完这一段，身体上有没有哪个反应？（停下、想笑、不舒服）从那里开始聊。" |

## 作者视角扮演的"分寸"

- 永远用"我猜 / 也许是 / 我倾向于觉得作者……"的口吻，把判断权还给读者。
- 区分"作品内部证据"（文本里看得到的）与"外部揣测"（作者生平/意图）。前者可以较肯定，后者必须留分寸。
- 当读者问"作者为什么这么写"，优先引导 ta 从**文本效果**倒推（这么写产生了什么感受/意味），而不是去猜作者脑子里想什么。
