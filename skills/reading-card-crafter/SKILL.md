# 读后感卡片工坊 (reading-card-crafter)

**命题**：一本书 → 一组可分享的小红书内容。这是 AI 时代阅读长出的新面向——阅读从私人独享，变成社交分享与发现。一本书的金句和感受，值得被做成别人愿意停下来读、并因此去找这本书的内容。

产出的不是"作文"，是**能被刷到、被点开、被种草**的内容。所以一切以小红书的阅读场景为准：手机竖屏、刷流秒决、情绪先行、信息密度高。

## 任务边界

**做（IN SCOPE）**
- 输入：书名（+ 作者）+ 一段金句 / 读后感片段 / 你想表达的点 +（可选）情绪倾向 / 目标读者 / 是否含剧透。
- 输出一套完整发布物料（见"产出结构"），全部为**文字**。
- 可按用户要求只产某一块（如"只要标题""只要金句卡片文案"）。

**不做（OUT OF SCOPE）**
- 不生成图片、不做视觉排版（不画卡片图）——只给卡片**上面的文字**与版面建议，配图由用户在小红书完成。
- 不做对谈式精读（book-dialogue）。
- 不把整本书划线整理成知识体系（knowledge-alchemy）。
- 不写独立成篇的长书评文章（read-to-write）；本 Skill 的正文是"笔记体"，短、口语、可扫读。
- 不编造书中没有的金句——所有引用必须是用户提供的原文，或明确标注"非原文，是提炼"。

## 产出结构（一套发布物料）

每次默认产出以下五块，用清晰小标题分隔，让用户能逐块取用：

```markdown
### 📌 标题（3 选 1）
（3 个备选标题，≤20 字，各有钩子，见 references/hook-bank.md）

### 🃏 金句卡片文案（2-3 张）
（每张：一句封面文字，≤14 字为宜，可配 1 行小字副标题。
 标注这句是【原文】还是【提炼】，原文不得改动一字。）

### 📝 正文读后感（笔记体）
（小红书风格：开篇 1 句钩子；中段分点短句，每点 1-3 行；
 情绪先行，感受在前、复述在后；克制用 emoji，2-4 个即可；
 结尾留一个"互动钩子"——一个问题或一句反问，引导评论。）

### #️⃣ 话题标签
（5-8 个。结构：1 个大类 #读书 + 1 个 #书名 + 2-3 个内容向标签
 + 1-2 个情绪/场景向标签。见 references/tag-strategy.md）

### 🎴 备选封面文案（1 组）
（1 个主标题 + 1 个副标题，用于自制封面图。）
```

## 风格硬约束

这些是"小红书读书笔记体"的区别于作文的关键，违反就读不出那味儿：

1. **标题有钩子**。≤20 字，开头给一个让人想点开的东西——反差、数字、共鸣、悬念。不要"《XX》读后感"这种平标题。详见 references/hook-bank.md。
2. **金句卡片字要少**。封面文字 ≤14 字最佳（手机一屏一行半能读完）。长句拆短。能不要标点就不要标点。
3. **正文短句分段**。一段不超过 3 行。一行能说完的别凑两句。用空行制造呼吸感。
4. **情绪先行**。先说"它让我……"，再说我为什么。读者是被感受打动的，不是被书评说服的。
5. **emoji 克制**。一条笔记 2-4 个，点缀用，不当主力。过量 emoji 显得廉价。
6. **结尾留钩子**。一个问题或一句反问，把读者从"看完"推向"想评论"。
7. **剧透管理**。默认不剧透关键情节/结局。若用户明确要带剧透讨论，标题与开头加"⚠️含剧透"提示。

## 标准工作流

> 引用任一 reference / asset 前，先用 Read 工具读取其完整内容，再动手。

1. **确认输入完整度**。至少要有：书名 + 一段可用的素材（金句或读后感点）。素材太薄时，先问用户一个具体问题补料（"这本书最戳你的是哪一句/哪一幕？"），而不是凭空生成——本 Skill 不编造书中没有的内容。
2. **读规范**。`Read references/hook-bank.md`（标题钩子）与 `references/tag-strategy.md`（标签），按它们的约束产出。
3. **定型情绪基调**。从用户素材里读出情绪（治愈 / 震撼 / 心碎 / 醒脑 / 温柔 …），全篇标题/卡片/正文/标签都服务这一个情绪，不要混搭。
4. **产出五块**。套用 assets/note-template.md 的骨架，遵守风格硬约束。金句明确标注【原文】/【提炼】。
5. **自检**。跑自检清单（见下）；格式有硬约束的部分（标题字数、标签数量、卡片字数）可用 `python scripts/validate.py <产出文件>` 快速校验。

## 自检清单

- [ ] 标题 3 个，各 ≤20 字，各有不同钩子，无"《XX》读后感"式平标题。
- [ ] 金句卡片每张封面文字 ≤14 字；引用句标注【原文】/【提炼】；原文一字未改。
- [ ] 正文段落 ≤3 行/段，情绪先行，结尾有互动钩子。
- [ ] emoji 全文 2-4 个。
- [ ] 标签 5-8 个，含 #读书、#书名，其余分内容向与情绪/场景向。
- [ ] 未剧透关键情节/结局（或已加 ⚠️ 含剧透提示）。
- [ ] 全篇情绪基调统一。
- [ ] validate.py 通过（exit=0）。

标题钩子库见 [references/hook-bank.md](references/hook-bank.md)，标签策略见 [references/tag-strategy.md](references/tag-strategy.md)，笔记骨架见 [assets/note-template.md](assets/note-template.md)。
