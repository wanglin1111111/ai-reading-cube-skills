# 链接策略 (linking-strategy)

链接是卡片盒的命脉。一张没链接的卡，和一条划线没区别。链接的价值不在"连了"，而在"**为什么连**"——关系类型才是知识。

## 五种关系类型

每次建链接，必须写清是哪种关系。括号里是建议的标注词：

1. **支持 / 证据（支持）**：A 卡的观点，被 B 卡提供证据或案例。
   - `→ [[B]]（支持：B 用实验证明了 A）`
2. **反例 / 张力（反例）**：B 与 A 矛盾，或给 A 划了边界。
   - `→ [[B]]（反例：B 说明 A 只在 X 条件下成立）`
3. **上位 / 下位（上位 / 下位）**：A 是 B 的更一般 / 更具体情形。
   - `→ [[B]]（上位：B 是 A 所属的更大框架）`
4. **因果 / 机制（导致）**：A 解释了 B 为什么发生，或反之。
   - `→ [[B]]（导致：A 是 B 的底层机制）`
5. **应用 / 场景（应用）**：A 是理论，B 是它落到某个具体场景的样子。
   - `→ [[B]]（应用：A 在 B 这个场景里表现为…）`

> 不确定关系类型时，宁可写一句"关联待定：感觉 A 和 B 有关，但关系还没想清"，也不要硬塞一个错的关系类型。错误的关系比没有关系更糟——它会把你的思考带偏。

## 跨书链接是金矿

同书内的链接通常是"顺着作者思路"，价值有限。**跨书链接**才是你自己的贡献——它把两个作者从没放在一起的东西，放到了一起。

跨书链接的找法：
- **同主题不同结论**：A 书说"X 导致 Y"，B 书说"X 抑制 Y"——这种张力最值得连，写清分歧在哪。
- **同现象不同解释**：两本书解释同一个现象，但用了不同机制——连起来，对比着看。
- **理论 + 案例**：A 书是理论，B 书（哪怕是一本传记/小说）是这个理论的活案例。
- **方法 + 反思**：A 书给方法，B 书质疑这类方法的副作用。

## 链接的写法

链接不是丢一个 `[[B]]` 就完事，要带**一句关系说明**：

```
- **链接**：→ [[TFAS-08]]（反例：TFAS-08 说直觉在熟悉领域可靠，
              这条说明它在复杂领域不可靠——边界在"复杂度"）
```

一句关系说明 = 一个被你显性化的思考。这才是知识沉淀。

## 链接密度

- 每张卡**至少尝试 1 条**链接。
- 不强求多。3 条写清关系的链接，胜过 10 条光溜溜的 `[[X]]`。
- 主题索引卡（入口卡）会反向链接到大量卡，这是正常的——它是枢纽。

## 关系图：把形状画出来

最后用文字把核心概念画成一张缩进/箭头图，让人看见这批知识的"形状"。例如：

```
决策质量
├─ 直觉（系统1）
│    ├─ 熟悉领域：可靠 [[TFAS-08]]
│    └─ 复杂领域：失灵 [[TFAS-12]] ──反例──> [[NOISE-03]]
└─ 推理（系统2）
     └─ 懒惰，常被系统1劫持 [[TFAS-05]] ──导致──> [[BIAS-锚定]]
```

这张图不是装饰——它能让你一眼看出"哪里知识密、哪里还空"，是下一步读什么的指南。
