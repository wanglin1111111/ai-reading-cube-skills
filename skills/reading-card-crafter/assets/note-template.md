# 小红书读书笔记骨架 (note-template)

这是一条读书笔记的完整物料骨架，照着填。每块的写法约束在 SKILL.md「风格硬约束」里，这里给的是结构与示例。

---

## 标题区

```
（3 选 1，≤20 字，分属不同钩子类型）
① [反差/共鸣/数字/悬念/极端情绪/场景/对比 任选其一]
② [换一种钩子]
③ [再换一种钩子]
```

## 金句卡片区

```
🃏 卡片1 ·【原文/提炼】
封面文字：________ （≤14 字）
副标题（可选）：________

🃏 卡片2 ·【原文/提炼】
封面文字：________ （≤14 字）
副标题（可选）：________
```

> 规则：原文一字不改，标注【原文】；非原文的提炼标注【提炼】。卡片上的字越少越有冲击力。

## 正文区（笔记体）

```
（开篇钩子 · 1 句）
________

（感受先行 · 1-2 句）
它让我 ________。

（分点 · 每点 1-3 行，短句）
① ________
② ________
③ ________

（互动钩子 · 结尾 1 句，一个问题或反问）
________
```

### 正文示例（参考语感，不要照抄）

> 开篇：本来是随手翻开，结果读到凌晨两点。
>
> 它让我重新想了一个我以为早就想明白的问题——什么算"被爱"。
>
> ① 克拉拉是个机器人，但她对"朋友"的忠诚，比书里任何一个人类都纯粹。
> ② 石黑一雄不喊口号，他只是把那个慢慢被替代的下午，写得很轻。轻到你读完才反应过来心口被压了一下。
> ③ 全书我最舍不得翻过去的，是结尾那句。不剧透，你自己去读。
>
> 你有没有过那种，被一个"非人类"的角色教会什么是人的时刻？

## 自检一句话

标题有钩子吗？卡片字够少吗？正文是不是"感受在前、复述在后"？结尾有没有把读者推向评论？标签结构四层齐了吗？情绪全篇统一吗？这五个"是"，就是一条合格的读书笔记物料。
