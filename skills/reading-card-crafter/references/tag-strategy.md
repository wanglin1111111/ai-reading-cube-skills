# 话题标签策略 (tag-strategy)

标签决定你的笔记被什么人搜到。读书笔记的标签不是越多越好，是**结构要对**。

## 标签结构（5-8 个为佳）

按这个金字塔配，缺层都会损失流量：

```
① 大类标签 ×1      —— 平台流量入口
   #读书 #阅读 #好书推荐

② 书名标签 ×1-2    —— 精准命中找这本书的人
   #书名 #作者名（书名短可只打书名）

③ 内容向标签 ×2-3   —— 命中"对这类话题感兴趣"的人
   （书的核心议题：#孤独 #原生家庭 #女性成长 #认知偏差 …）

④ 情绪/场景向 ×1-2  —— 命中"此刻正处在这种状态"的人
   （#深夜读物 #通勤书单 #治愈书单 #适合秋天读的书 …）
```

## 为什么是这个结构

- **大类标签**给你基础曝光池——它是"读书"这个赛道的大门。
- **书名标签**是把"已经在找这本书的人"接住——这波人转化率最高（会收藏、会关注）。
- **内容向标签**是破圈利器——一个只对"原生家庭"感兴趣、根本不认识这本书的人，会因为这个标签刷到你。
- **情绪/场景向**是种草利器——人在特定情境下（失眠、失恋、想逃离）的搜索意图极强，转化成"立刻去找书"的概率最高。

## 配标签的几条规则

1. **别全用大类**。全是 #读书 #阅读 #好书推荐，等于没标签——你进的是最拥挤的池子，被淹没。
2. **别用冷门到没人搜的**。标签没人搜 = 没流量。拿不准时，优先用你能确定"真的会有人搜"的词。
3. **内容向标签要从书的核心母题来**，别贪多。一本书写 3 个内容向标签是极限，多了反而稀释。
4. **情绪向标签要和正文情绪一致**。正文是治愈，标签就别挂 #致郁。
5. **数量克制**：5-8 个。少于 5 暴露面不够，多于 8 平台可能判定堆砌降权。

## 配套示例

输入：《克拉拉与太阳》，情绪：温柔又心碎

```
#读书 （大类）
#克拉拉与太阳 #石黑一雄 （书名+作者）
#人工智能 #孤独 #爱 （内容向，取核心议题）
#治愈书单 （情绪/场景向）
```

共 7 个，结构完整，情绪一致。
