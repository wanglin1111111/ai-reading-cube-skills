# 四种文体骨架 (genre-skeletons)

同一段阅读经历，写成不同文体，骨架天差地别。先定文体，再取骨架。

---

## 1. 读后感（重心：这本书在我身上发生了什么）

读后感不是书评。它不对外负责，只对你自己诚实。书是锚，你的感受和变化才是主。

### 骨架
```
① 触发点（1 段）
   一个具体的瞬间——读到哪一句/哪一幕时你被打到了。用场景，不要用概括。

② 此前的我（1 段）
   在遇到这本书之前，你对这个母题是怎么想的/怎么活的？
   （这一段是后面的"变化"的参照系，没有它，变化显得空。）

③ 书做了什么（1-2 段）
   这本书怎么动了你？不要复述全书，只讲它"击中你"的那一击。
   夹一两个原文短引，作为支点。

④ 此后的我（1 段）
   读完后你有什么不一样？想法变了？做了某个决定？
   （诚实——如果只是"略有触动"也没关系，别夸大。）

⑤ 落点（1 段）
   一个收束。可以是一个还在想的问题，不必是结论。
```

### 命题要点
命题落在"它如何动了你"，要小、要具体。
- ❌ "论《活着》中的苦难"（太空）
- ✅ "我爸生病那年我没哭，读《活着》那晚我哭了——我才发现我把'坚强'当成了麻木"

---

## 2. 书评（重心：这本书写得怎么样）

书评要对陌生的潜在读者负责：给判断、给理由、少剧透。

### 骨架
```
① 判断先行（1 段）
   一句话总判断 + 给谁看 / 不给谁看。别憋到最后才说。

② 它在做什么（1-2 段）
   这本书想解决什么问题、用了什么方式。交代足够读者判断的背景。

③ 好在哪 / 弱在哪（核心，2-3 段）
   每段一个论点，配书里的具体证据（不是"写得很深刻"，而是"第 X 章那个处理，
   让我……"）。好的书评敢于同时讲优点和缺点。

④ 横向坐标（1 段，可选）
   和同类书比，它站在哪。给读者一个坐标系。

⑤ 收束（1 段）
   重申判断 + 一句可执行的"如果你是 XX 读者，读它"。
```

### 命题要点
命题落在"你的总判断 + 最强的那个理由"。
- ✅ "《XX》野心很大但落地散乱——它的核心洞见值前三章，后面是重复"

---

## 3. 小故事（重心：把书的母题嫁接进你的一段经历）

不是写这本书的梗概，是借这本书的某个母题，讲一个**你自己的**故事。

### 骨架
```
① 一个具体场景起笔（1 段）
   人物、时间、地点、一个动作。不要"感悟式"开头。

② 母题的嫁接点（藏在叙事里）
   这本书的哪个母题（告别/选择/等待/背叛…）在这段经历里活着？
   不要点破，让它从情节里长出来。

③ 转折（1 段）
   一个改变走向的具体事件。

④ 留白式收尾（1 段）
   不总结道理。停在一个画面、一个未完成的动作、一句没说出口的话。
```

### 命题要点
命题落在"哪个瞬间值得写成故事"。
- ✅ "爷爷最后一次给我盛饭那顿——我想借《XXX》里那个'告别'的母题写下来"

---

## 4. 随笔（重心：由这本书漫出去想到的东西）

随笔最自由，也最难。它要的不是结构完整，是**有腔调、有真东西的漫想**。

### 骨架（更松，但不是没有）
```
① 一个触发点（这本书里的某个细节/一句话）起笔
② 由它漫出去——联想、记忆、别的书、新闻、一个画面……
③ 漫的过程中，得有至少一个"真东西"——一个你自己琢磨出来的、
   别人没这么说过的小洞见。这是随笔的命。
④ 收束可以很淡，甚至戛然而止。
```

### 命题要点
命题落在"一个让你想东想西的触发点"。
- ✅ "《XX》里那盏灯让我想起小时候楼道里的声控灯——我突然想搞清楚'等待被点亮'这件事"

---

## 通用提醒（所有文体）

- **开头 3 行定生死**。用一个具体场景/细节/反差起笔，不要"最近我读了一本书……"。
- **具体压倒概括**。一个细节 > 一句道理。能写"那天雨很大，伞骨断了一根"就别写"那天很倒霉"。
- **删掉所有"我觉得""我认为"**。你的文章里当然是你觉得，不用声明。
- **结尾别强行升华**。一个好的结尾是"让读者自己接着想"，不是替读者总结人生。
