# 追问生成法 (follow-up-questions)

这是本 Skill 最关键的能力：生成**有信息量的追问**。一个好追问，比一段好解读更值钱——它让读者自己走到理解。

> 什么时候读这个文件：当你要开口回应读者，却拿不准"第一句该问什么"，或发现自己的追问太空泛（"你指什么呀"）时，来这里取技法与题库。

## 好追问的三个特征

1. **有信息量**：问里带一个具体的指向，而不是开放式空问。
   - 空：「你指的是什么？」
   - 有信息量：「你说'感觉很怪'——是盖茨比第一次出场那个微笑让你觉得怪，还是他盯着绿灯那个动作？」
2. **指向具体**：锚定到一个情节/一句话/一个人物动作，让读者有抓手可回。
3. **跳一下够得着**：难度卡在读者"想想能答，但不想想就能答"。太易=无感，太难=放弃。

判断标准：读者看到这个追问，第一反应是"哦让我想想"，而不是"我不知道"或"这还用问"。

## 六种追问技法

每种配一句可直接套用的句式。读者抛来疑问时，按情境挑一种。

### 1. 聚焦（把模糊感受钉到一个具体点上）
读者说"这段我没感觉/看不懂/怪怪的"时用——把模糊钉到具体。

- 句式：「你说 X——是哪一刻开始 X 的？往前一点，发生了什么？」
- 例：读者说《活着》"看得心里堵"→「堵——是从哪个瞬间开始堵的？福贵输光家产那一刻，还是后来某件事？」

### 2. 换位（让读者站进角色鞋子里）
读者问"这个角色为什么这么做"时用——别替角色回答，让读者自己站进去。

- 句式：「如果你是这个角色，那一刻你为什么不直接 X？」
- 例：读者问"安娜为什么不去离婚"→「如果你是安娜，在那个年代的俄国，你卡在哪——是离不了，还是不敢离，还是不想离？」

### 3. 反例（用一个例外去扰动读者的第一直觉）
读者下了一个概括性判断时用——给个反例，逼 ta 修正或细化判断。

- 句式：「你说全都是 X——那书里有没有哪一个其实不 X？ta 为什么不同？」
- 例：读者说《百年孤独》"每个人都孤独"→「都孤独——那你觉得上校的孤独，和阿玛兰塔的孤独，是同一种吗？」

### 4. 拎母题（把小问题往大母题上拎）
读者问的是一个具体细节时用——暗示这个细节背后有更大的东西。

- 句式：「你注意到的这个细节，会不会其实是一个更大的问题的缩影——……？」
- 例：读者问"盖茨比为什么盯绿灯"→「盯绿灯这个动作，会不会其实是'人如何与一个回不去的过去共处'这个大问题的一个缩影？」

### 5. 交给身体（从身体反应切入）
读者说不出感受、或问题太空时用——身体是最诚实的入口。

- 句式：「你读完这一段，身体上有没有哪个反应？（停下、想笑、不舒服、想合上书）从那里开始聊。」
- 例：读者问"这首诗什么意思"→「先别管意思——你第一遍读完，最强烈的身体感觉是什么？从那里开始。」

### 6. 还给读者（把"读懂"的责任交回去）
读者问"作者到底想说什么"时用——温和地把问题还给 ta，因为"作者意图"本就无定论。

- 句式：「'作者想说什么'可能没有标准答案——但你读完，你自己最想说的是什么？」
- 例：读者问"卡夫卡《变形记》到底想表达什么"→「这个问题卡夫卡本人可能也答不清。但你读完，最让你难受的是哪一点？从你的难受出发，比从'作者意图'出发更靠谱。」

## 按文体选追问

不同文体，默认主用的技法不同：

| 文体 | 首选技法 | 次选 |
|---|---|---|
| 小说/叙事 | 换位、聚焦、拎母题 | 反例 |
| 散文/随笔 | 交给身体、聚焦 | 拎母题 |
| 诗歌 | 交给身体（几乎只用这个） | 聚焦（抓意象） |
| 非虚构/论说 | 反例（"你认同吗？有反例吗？"） | 拎母题 |
| 哲学/思想 | 反例、换位（思想实验） | 拎母题 |
| 科普 | 聚焦（"你脑子里的画面是什么？"） | 换位 |

> 诗歌的特殊性：诗歌最忌讳"翻译式解读"。对诗，**几乎只用「交给身体」和「聚焦意象」**——问颜色、温度、声音、停顿，允许多义，绝不下唯一正解。

## 坏追问对照表

| 坏追问（要避免） | 为什么坏 | 改成 |
|---|---|---|
| 「你指什么呀？」 | 零信息量，把球完全踢回去，读者会觉得被敷衍 | 给两个具体选项让读者选：「是 A 还是 B？」 |
| 「你觉得呢？」（单独出现） | 太空，读者不知从何答起 | 先给一句你的观察，再问：「我注意到 X，你怎么看？」 |
| 「你能详细说说吗？」 | 把读者当被采访者，本末倒置 | 改成聚焦式：「具体是哪一部分？举个例子。」 |
| 一口气连问 4-5 个 | 读者答不过来，等于没问 | 一轮最多 1-2 个追问 |
| 问里有答案（诱导式） | 「你是不是觉得他很自私？」——这不算追问，是替读者答了 | 开放但有指向：「你对这个人，第一反应是喜欢还是反感？」 |

## 一句话心法

> 追问的目的不是"考倒读者"，是"帮读者看见自己还没看见的那个台阶"。读者答得出、且答完会有"哦——"的感觉，就是好追问。
