# 知识卡片骨架 (card-template)

每张原子卡照这个骨架填。字段不要随意增减，保持知识库结构一致。

---

## 单张卡片

```markdown
### [[卡片ID]] 卡片标题（一句话命题）

- **出处**：《书名》· 章节名 / 页码（出处未详则标"出处未详"）
- **原文**：（原划线，一字不改保留，作为证据）
- **我的复述**：（用自己的话重写，≤3 句。复述不出写「待消化」。）
- **链接**：
  - → [[另一卡ID]]（关系类型：一句说明）
  - → [[又一卡ID]]（关系类型：一句说明）
- **标签**：#主题1 #主题2
```

### 填写示例

```markdown
### [[TFAS-12]] 复杂情境下，直觉的可靠度随复杂度指数下降

- **出处**：《思考，快与慢》· 第一部 / p.98
- **原文**："在那些有规律可循、且能提供快速反馈的环境里，直觉可以练就；除此之外，它往往是一种错觉。"
- **我的复述**：直觉能不能信，不看你"熟不熟"，看那个领域有没有清晰规律和快速反馈。下棋、 firefighting 有，所以直觉灵；股市、长期政策没有，所以直觉是幻觉。
- **链接**：
  - → [[TFAS-08]]（张力：TFAS-08 说直觉在熟悉领域可靠——这条给它画了边界，边界是"复杂度/反馈速度"）
  - → [[NOISE-03]]（反例：NOISE-03 用法官判例说明，连"专家"在低反馈领域也靠不住）
  - → [[ME-07]]（应用：我自己的——上次凭直觉选 offer 翻车，就是因为招聘是低反馈复杂决策）
- **标签**：#决策 #直觉 #认知偏差
```

## 主题索引卡（枢纽卡）

把一批相关卡按主题聚到一起，作为入口。

```markdown
## 主题索引：决策与偏差

- **核心命题**：（这个主题下，你最想记住的一两句话）
- **相关卡片**：
  - [[TFAS-05]] 系统2懒惰，常被系统1劫持
  - [[TFAS-08]] 熟悉领域直觉可靠
  - [[TFAS-12]] 复杂情境直觉失灵
  - [[BIAS-锚定]] 锚定效应……
  - [[NOISE-03]] 低反馈领域专家也靠不住
- **我的总评**：（这个主题读到现在，我自己形成的判断——可空）
```

## 自检一句话

每张卡：是不是只讲了一个想法？标题是不是命题而非主题？有没有"我的复述"（不是照抄）？链接有没有写清关系类型？这四问都"是"，才是一张会生长的卡。
