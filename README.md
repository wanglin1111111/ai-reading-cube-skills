## book-dialogue · 与书对谈

**命题**：一本书 → 一个可对话的对象。

读书时最孤独的时刻，是卡在一个点上没人可问、读完一肚子话没人可聊。这个 Skill 把一本书变成可以对话的对象——你问它答，它也反问你。它用苏格拉底式追问引导你自己想明白，按小说/散文/诗歌/非虚构/哲学/科普切换打法，必要时切「作者视角」揣摩、做主题深挖与跨文本勾连。

### 三个核心原则

1. **先问后答** —— 收到疑问先回 1-2 个有信息量的追问，探明你卡在哪，再给解读。
2. **追问，不灌输** —— 宁可把结论拆成让你跳一下够得着的小问题，也不把道理拍上去。
3. **不剧透** —— 你读到哪，对话就只活在那个世界里。后续关键情节一字不越。

### 试试这样问

- 「我刚读完《活着》第一章，福贵为什么要把家产输光？」
- 「《百年孤独》开头那句'许多年之后……'到底好在哪？」
- 「《小王子》里狐狸说的'驯养'，和我养猫是一回事吗？」

## 【Skill 面】参展信息

### ① book-dialogue · 与书对谈

**一句话说明**：把一本书变成可以对话的对象——你问它答、它反问你，读书从单向接收变成双向对话。

**创作缘起（100 字内）**：读书时常卡在一个点没人可问，读完一肚子话没人可聊。我做这个 Skill，是想让一本书不再读完就合上，而是能被反复追问、被聊透。AI 让阅读从一个人的事，变成一场随时能展开的对话。

### ② reading-card-crafter · 读后感卡片工坊

**一句话说明**：把一本书的金句和感受，做成可以直接发小红书的标题、卡片文案与读书笔记。

**创作缘起（100 字内）**：划了那么多线、动了那么多念头，最后都没能变成一条能分享出去的内容。这个 Skill 想把"读到的"变成"被人看见的"——让好书借你的感受被更多人发现。阅读因此从私人独享，长出社交分享的新面向。

### ③ knowledge-alchemy · 知识炼金

**一句话说明**：把散落的读书划线，炼成原子化的知识卡片与互链网络，让笔记真正沉淀、能被调用。

**创作缘起（100 字内）**：我们都在疯狂划线，却几乎从不回看——划线只是"我懂了"的错觉。我用卡片盒笔记法的理念做这个 Skill，把每条划线逼成一张能互链、会生长的卡片。让阅读从碎片，长成一座可调用的知识库。

### ④ read-to-write · 以读促写

**一句话说明**：从一本书出发，找到只属于你的写作命题，搭好脚手架，一步步陪你写出一篇自己的文字。

**创作缘起（100 字内）**：很多次读完想写点什么，却对着空白页发呆。这个 Skill 不替你写，而是帮你找到"书 × 你"的那个交叉点，把写作的坎拆成台阶。因为最好的阅读回应，是你自己写出来的那篇字。
