# 卡片盒笔记法细则 (zettelkasten-rules)

卡片盒（Zettelkasten）的精髓不是"做很多笔记"，而是"让笔记之间能对话"。下面是炼卡时的细则。

## 原子化：一张卡 = 一个想法

**判断标准**：这张卡能否被单独拿出来讨论，而不需要别的卡做上下文？
- 能 → 合格的原子卡。
- 不能（拿掉别的卡就看不懂）→ 要么补全它，要么它本该是另一张卡的一部分。

**常见错误**：把一整节书的划线塞进一张卡。一节里通常有 2-4 个独立观点，应该拆成 2-4 张卡。

### 拆分信号
一条划线里出现这些，多半该拆：
- "一方面……另一方面……" → 两张。
- "第一……第二……第三……" → 三张（或合并成一个"清单卡"，但清单卡是次选）。
- "A 是 B。但 C 会让 A 变成 D。" → "A 是 B" 一张，"C 对 A 的影响" 一张。

## 标题：一句话命题

卡片标题不是标签，是一个**能被判断真假的陈述句**。

| ❌ 坏标题（主题式） | ✅ 好标题（命题式） |
|---|---|
| 关于专注力 | 主动分心的成本，随任务复杂度指数上升 |
| 划线的意义 | 划线制造"已掌握"的错觉，但不产生回忆 |
| 议价技巧 | 先报价的一方，会无意识地把锚拉向自己的预期 |

命题式标题的好处：未来你扫一眼标题，就知道这张卡"主张什么"，能直接判断它和你正在想的问题有没有关。

## 复述：用自己的话

**照抄原文 = 没过脑子。** 划线时你觉得懂了，但那只是"识别"，不是"理解"。复述才是理解的检验。

复述规则：
1. 合上原文，凭记忆写。写不出 → 回看 → 再合上重写。
2. 用**比你平时更朴素**的话。能说人话别说术语。
3. ≤3 句。写多了说明你还没压缩到本质。
4. 实在复述不出，**诚实标注「待消化」**，并把卡留在"待办"区。这比写一张假装懂的卡有价值得多。

## 卡片 ID 与命名

- ID 用稳定、可排序的格式。推荐：`来源缩写-序号`，如 `TFAS-12`（Thinking Fast and Slow 第 12 条）或 `日期-序号` 如 `20260810-03`。
- ID 一旦赋定不再变（链接靠它）。
- 跨书卡（你自己的综合想法）用独立命名区段，如 `ME-01`（My Edition），区别于直接源自某书的卡。

## 标签：少而准

- 一张卡 2-3 个标签。多了等于没标。
- 标签是**主题**（#决策 #记忆 #动机），不是体裁或书名（书名放"出处"字段）。
- 宁可复用已有标签，也不要每次造新词。标签 inflation 是知识库腐烂的开始。

## 三类卡，分清

| 类型 | 说明 | 例子 |
|---|---|---|
| 文献卡 | 忠实记录"某书说了什么"，带出处 | 《思考，快与慢》说系统1会… |
| 永久卡 | 你自己消化后的命题，是知识库主体 | 主动分心的成本随复杂度指数上升 |
| 索引卡 | 某主题的入口，列出相关卡 | 「决策偏差」主题下的卡片清单 |

本 Skill 产出以**永久卡**为主，文献卡作为永久卡的"出处"字段融合进去。
