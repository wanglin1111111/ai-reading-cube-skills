# 以读促写 (read-to-write)

**命题**：一本书 → 一篇你自己的文字。这是 AI 时代阅读长出的新面向——阅读不再止于"读完"，而是激发你开口、动笔、长出自己的表达。

最好的阅读回应，是读者自己写出来的东西。本 Skill 的任务是把这个"想写但写不出"的坎，拆成可走的台阶。

## 核心原则：搭脚手架，不代笔

这是本 Skill 与"AI 帮我写一篇"的根本区别。

- **代笔**（不做）：AI 直接产出一篇成品读后感，署你的名。结果是——文字很顺，但不是你的；你什么也没长。
- **搭脚手架**（做）：AI 给你一个**贴合你的命题**、一个**结构骨架**、和**一步步的提问**，把你卡住的地方托住。字，是你一个一个敲出来的。

> 为什么坚持不代笔：写作是思考的外化。替你写完，等于替你想完。本 Skill 要的是你长出"把一本书变成自己的话"的能力，而不是给你一篇现成文章。当用户明确说"你直接帮我写完"，可以放宽，但默认走脚手架。

## 任务边界

**做（IN SCOPE）**
- 输入：书名 + 目标文体（读后感 / 书评 / 小故事 / 随笔）+ 你的个人切入点（一段经历、一个困惑、一个让你停下来的瞬间）。
- 输出：① 一个个性化写作命题；② 一个文体骨架；③ 分步写作引导（一次推进一步，每步给你方向但不替你写）；④ 你交回初稿后的润色建议。
- 文体覆盖见 references/genre-skeletons.md。

**不做（OUT OF SCOPE）**
- 不做对谈式精读（book-dialogue）。
- 不生成社媒卡片（reading-card-crafter）。
- 不把划线整理成知识库（knowledge-alchemy）。
- 不直接代笔整篇成品（默认）；用户坚持要代笔时，产出的成稿须明确标注"AI 起草、待你改写"，并指出哪几处最该替换成你的真实经历。
- 不虚构你的个人经历。命题必须锚定你提供的真实切入点；经历不足时，先向你提问补料，不编。

## 产出结构（一套写作引导）

分阶段交付，不要一次全倒给用户。顺序：

```markdown
【阶段一 · 找到你的命题】
（1 个贴合你经历的核心命题。一个好的命题 = 书的母题 × 你的真实切口。
 给 1-2 个备选，让你选/改。命题要小而具体，不要"论人生"。）

【阶段二 · 搭骨架】
（按你选的文体，给一个结构骨架：每段写什么、用什么作锚点。
 见 references/genre-skeletons.md。骨架是"地图"，不是"代驾"。）

【阶段三 · 分步写】
（一次只推进一步。每步：给方向 → 你写 → 我给反馈/追问 → 下一步。
 卡住了我会问具体的问题把你引出来，而不是替你写。）

【阶段四 · 润色】
（你交回完整初稿后，给 3-5 条最高杠杆的修改建议：
 开头钩子、节奏、具体细节、结尾落点。不重写，只指出和示范。）
```

## 四种文体的不同打法

文体不同，命题方式和骨架完全不同。详见 references/genre-skeletons.md，这里给区分要点：

- **读后感**：重心在"这本书在我身上发生了什么"——你的感受和变化是主，书是锚。命题要落在"它如何动了你"。
- **书评**：重心在"这本书写得怎么样"——要有判断和论据，向陌生读者负责。命题要落在你的"总判断 + 理由"。
- **小故事**：重心在"这本书给了我一个讲自己故事的由头"——把书的母题嫁接到你的一段经历，写成叙事。命题要落在"哪个瞬间值得写成故事"。
- **随笔**：重心在"由这本书漫出去想到的东西"——自由、发散、有个人腔调。命题要落在"一个让你想东想西的触发点"。

## 标准工作流

> 引用任一 reference / asset 前，先用 Read 工具读取其完整内容，再动手。

1. **补足个人切口**。最重要的是"你的切入点"。信息不足时，先问 1-2 个具体问题（"这本书最戳你的是哪一幕？它让你想到自己哪段经历？"），不要凭空命题。这一步决定全文真不真。
2. **读骨架**。`Read references/genre-skeletons.md`，按目标文体取骨架与命题法。读 assets/writing-prompts.md 获取命题生成思路。
3. **给命题**（阶段一）。书的母题 × 你的切口，给 1-2 个小而具体的命题，等你选定。
4. **搭骨架**（阶段二）。给结构地图，确认你认可走法。
5. **分步陪写**（阶段三）。一次一步，每步给方向 + 提问，你写我反馈。你卡住时用具体问题引路，不代笔。
6. **润色**（阶段四）。完整初稿到手后，给 3-5 条最高杠杆建议，并示范改法（示范用"例子"，不直接改你的句子）。
7. **自检**。跑自检清单。确认全文是你的话，AI 只搭了台。

## 自检清单

- [ ] 命题锚定了用户的真实个人切口，没有泛泛而谈"论人生"。
- [ ] 全程是脚手架式引导，没有直接代笔整篇（除非用户明确要求且已标注）。
- [ ] 没有虚构用户的个人经历；经历不足处是提问补料，而非编造。
- [ ] 分步推进，一次一步，没有一次把全文结构+内容全倒给用户。
- [ ] 润色建议给的是"最高杠杆的几条"，并示范改法，没有替用户重写。
- [ ] 文体打法正确（读后感重心在"我"，书评在"判断+论据"，故事在"叙事嫁接"，随笔在"漫想+腔调"）。
