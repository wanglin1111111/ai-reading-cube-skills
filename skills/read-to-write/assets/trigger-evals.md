# 触发可靠性评估清单 (trigger-evals)

> 本文件用于校准 read-to-write 的 description 触发率，方法对齐 agentskills.io/skill-creation/optimizing-descriptions。
> **测试方法说明**：用"全新上下文子代理做盲判路由"作 trigger_rate 的代理指标——给干净上下文的代理看 4 个 Skill 的 description + 1 条查询，判路由到哪个。这测的是"description 对仔细阅读者是否可辨别"，是触发可靠的必要条件；真实生产触发率还依赖平台相似度匹配算法，无法在对话内完全复现。

## Should-not-trigger（不应触发，10 条 near-miss）

这些查询共享关键词（读后感、书评、写、文章），但真实意图不是"写一篇自己的文字"，应路由到相邻 Skill 或 NONE。

| # | 查询 | 真实意图 | 应路由到 |
|---|---|---|---|
| N1 | 把这段读后感做成小红书卡片发出去 | 社媒卡片 | reading-card-crafter(B) |
| N2 | 把这些划线整理成笔记 | 知识结构化 | knowledge-alchemy(C) |
| N3 | 帮我深读《思考快与慢》的系统1机制 | 对谈精读 | book-dialogue(A) |
| N4 | 我想聊聊这本书的一个困惑 | 对谈精读 | book-dialogue(A) |
| N5 | 把这段《红楼梦》的英文翻译成中文 | 翻译 | NONE |
| N6 | 这本书作者是谁 | 事实查询 | NONE |
| N7 | 帮我找几本类似的书 | 书目推荐 | NONE |
| N8 | 帮我给读书会写个讨论提纲 | 生成提纲 | NONE（边界案，见下） |
| N9 | 《百年孤独》人物关系太乱，画个图 | 信息可视化 | NONE |

> **N8「讨论提纲」是已知边界案**：前序测试中 book-dialogue v1.2 修补后该查询稳定为 NONE。本轮验证它不会误触到 D（D 是"写你自己的文字"，提纲不是个人文字）。D 的 description 当前用"读后感/书评/小故事/随笔"列举，理论上不覆盖提纲，但需实测确认。

### 测试详情（v1.0，2026-08-10）

**方法**：综合 batch 盲判（24 条查询覆盖 3 个 skill，随机化顺序）+ MED 项重测。共 28+ 次独立子代理判定。

**本 skill 相关查询（应触发的 T1-T7）**：写读后感/写小故事/写随笔/教写书评/不知从哪下笔——均判 D（多数 HIGH，"完整书评"项重测后由 MED 升至 HIGH），0 失败。

**关键边界案 N8「帮我给读书会写个讨论提纲」**：
- 本轮（含 2 次独立重测）：**稳定为 NONE**——判别理由"D 只面向读后感/书评/小故事/随笔等个人写作文体，讨论提纲不是个人文字"。
- **结论**：N8 不误触到 D。D 的 description 当前用文体列举（读后感/书评/小故事/随笔）已足够划清与"讨论提纲"的边界，**无需额外修改**。

**干扰项 Q21「写读后感 + 整理进知识库」（双意图）**：2 次判定均为 D·HIGH——正确按核心意图（写读后感）路由，未被次要意图（知识库）带偏到 C。路由按核心意图判的逻辑生效。

**结论**：read-to-write 的 description 触发边界清晰，无过度触发、无漏触发。
